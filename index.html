☁ Respaldo en la nube (gratis)

Guarda una copia de todos tus datos (con fotos) en tu propia cuenta de Firebase, para no perderlos aunque se dañe o se pierda el celular.

Configuración (una sola vez, unos 10 minutos):

1. Entra a console.firebase.google.com con tu cuenta de Google → Crear un proyecto (el nombre es libre; desactiva Google Analytics).

2. Menú Compilación → Authentication → Comenzar → Correo electrónico/contraseña → actívalo → Guardar.

3. Compilación → Firestore Database → Crear base de datos → elige cualquier ubicación → modo producción → Habilitar.

4. En Firestore, pestaña Reglas: borra lo que haya, pega estas reglas y toca Publicar:

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /respaldos/{uid}/{document=**} {
      allow read, write: if request.auth != null
                         && request.auth.uid == uid;
    }
  }
}

5. Engranaje ⚙ → Configuración del proyecto → sección "Tus apps" → ícono web </> → ponle un nombre y registra (sin Hosting). Copia el bloque firebaseConfig y pégalo aquí:

Crea tu cuenta de respaldo (correo y contraseña de 6 o más caracteres). Si ya la creaste, inicia sesión. Anota bien la contraseña: si la olvidas puedes pedir un correo para cambiarla.

✨ Mejora de redacción con IA (opcional)

Sin nada configurado, el botón "Mejorar" en la Bitácora solo hace una limpieza básica del texto (ortografía y orden). Si quieres que además redacte mejor de verdad, puedes conectar una clave gratuita de Google Gemini — no tiene costo ni pide tarjeta.

Cómo obtenerla: entra a aistudio.google.com desde tu celular o computador, inicia sesión con tu cuenta de Google, busca "Get API key" y cópiala aquí abajo.
